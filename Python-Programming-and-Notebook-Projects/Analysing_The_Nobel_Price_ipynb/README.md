1. Project Overview
This project explores and visualizes historical Nobel Prize data to uncover patterns, trends, and interesting facts. Using Plotly, Matplotlib, and Seaborn, we perform advanced data analysis and create interactive and static visualizations.
The analysis covers:
•	Prize distribution across categories
•	Trends in the number of prizes over time
•	Gender-based patterns in Nobel Prize winners
•	Geographical distribution of Nobel Prize wins
•	Age distribution of laureates
•	Regional research breakdowns


2. Objectives
By the end of this analysis, we aim to:
1.	Understand how Nobel Prizes are distributed across different fields.
2.	Explore gender representation in Nobel Prize history.
3.	Identify trends over time in Nobel Prize awards.
4.	Map the countries with the most Nobel Prizes.
5.	Examine the regional breakdown of laureates.
6.	Analyze age patterns among Nobel Prize winners.


3. Analysis & Visualizations
Bar & Donut Charts — Prize Categories & Women Winning Prizes
•	Visualizing Nobel Prize counts across categories.
•	Highlighting female representation in Nobel Prize history.
Trend Analysis with Matplotlib
•	Showing how Nobel Prize awards have evolved over time.
Choropleth Map — Countries with the Most Prizes
•	Geographic mapping of Nobel Prize distribution by country.
Sunburst Chart — Regional Breakdown
•	Detailed visualization of research locations and regional achievements.
Age Analysis
•	Distribution of laureate ages at the time of the award.
•	Identifying patterns and outliers.


4. Technologies Used
•	Python 3.x
•	Pandas — Data manipulation & cleaning
•	Plotly Express — Interactive charts
•	Matplotlib — Static visualizations
•	Seaborn — Statistical data visualization
•	Google Colab / Jupyter Notebook — Development environment


5. Learning Points
•	Combining interactive (Plotly) and static (Matplotlib, Seaborn) visualizations.
•	Advanced grouping, filtering, and aggregation with Pandas.
•	Effective use of choropleth and sunburst charts for geographical and hierarchical data.
•	Extracting insights from historical datasets.
