1. Project Overview
This project is a full-featured RESTful blog application built using Python and Flask, implementing the CRUD (Create, Read, Update, Delete) functionality through RESTful routes.
The aim is to demonstrate REST principles in a real-world web application, where blog posts can be created, retrieved, updated, and deleted seamlessly.
Advanced – Blog Capstone Project Part 3: RESTful Routing.


2.	 Features
•	GET: Retrieve and display all blog posts.
•	POST: Create and publish new blog posts.
•	PUT / PATCH: Edit existing blog posts.
•	DELETE: Remove blog posts from the database.
•	Clean, minimal, and user-friendly interface.


3.	Tech Stack
•	Language: Python 3.x
•	Framework: Flask
•	Database: SQLite (for local development)
•	Templating Engine: Jinja2 (Flask default)
•	CSS Framework: Bootstrap (optional for styling)


4.	Learning Outcomes
•	Understand and implement RESTful routing in Flask.
•	Perform CRUD operations in a Flask app.
•	Work with Flask-WTF forms for user input.
•	Connect a Flask app to an SQLite database.
•	Structure Flask applications for scalability.
