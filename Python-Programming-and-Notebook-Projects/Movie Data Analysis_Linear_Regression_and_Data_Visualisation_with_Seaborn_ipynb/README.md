1. Objectives
By the end of this project, you will:
1.	Explore and clean a movie dataset.
2.	Investigate films with zero revenue and handle missing or inconsistent values.
3.	Filter data based on multiple conditions (e.g., international films).
4.	Create bubble charts for visual representation of multi-dimensional data.
5.	Apply floor division to group years into decades.
6.	Use Seaborn to plot linear regressions.
7.	Implement regression modeling using scikit-learn.


2. Key Steps & Analysis
Data Cleaning
•	Handle missing values.
•	Identify and investigate films with zero revenue.
•	Remove unnecessary columns.
Filtering Data
•	Select international films using multiple conditions in Pandas.
Visualizing Data
•	Bubble charts for visualizing relationships between budget, revenue, and ratings.
•	Group films into decades using floor division.
Regression Analysis
•	Seaborn Regression Plots to show relationships between variables.
•	Build a linear regression model with scikit-learn to predict revenue based on other features.


3. Technologies Used
•	Python 3.x
•	Pandas — Data manipulation
•	Seaborn — Data visualization
•	Matplotlib — Plot customization
•	scikit-learn — Machine learning (linear regression)
•	Jupyter Notebook — Analysis environment


4. Learning Points
•	Handling zero and missing values effectively.
•	Creating multi-dimensional charts with Seaborn.
•	Converting continuous years into grouped decades.
•	Building and interpreting a linear regression model.
