1.	Project Overview
This project demonstrates time series data analysis and visualization using Google Trends and other datasets.
It covers the complete workflow from data exploration, cleaning, and resampling, to creating insightful visualizations with Matplotlib.
Google Trends Data: Resampling and Visualising Time Series.


2.	Objectives
•	Explore and understand Google Trends search data.
•	Apply time series resampling techniques to handle different granularities.
•	Build custom visualizations to uncover trends and patterns.
•	Work with multiple datasets (Tesla, Bitcoin, Unemployment rates).
•	Demonstrate professional-level plotting skills with Matplotlib.


3.	Tech Stack
•	Language: Python 3.x
•	Libraries:
o	pandas – data manipulation
o	matplotlib – data visualization
o	numpy – numerical operations
o	datetime – date/time handling


4.	Key Steps Implemented
Data Exploration
•	Loaded Google Trends search data and inspected structure.
•	Checked missing values and time ranges.
•	Identified trends in keyword searches.
 Data Cleaning & Resampling
•	Resampled daily data into monthly and yearly frequencies.
•	Handled missing values by interpolation.
•	Created rolling averages for smoothing trends.
Visualisations
•	Tesla – Line charts with custom date formatting.
•	Bitcoin – Different line styles & markers.
•	Unemployment – Grid-based visualizations to compare data.
•	Combined plots for comparison.
Advanced Plot Formatting
•	Used DateFormatter and Locator for custom time axis ticks.
•	Added grid lines, annotations, and legends for clarity.


5.	Learning Points
•	How to structure a time series data pipeline.
•	Importance of resampling for trend analysis.
•	Effective data storytelling with charts.
•	Matplotlib customization for professional plots.
