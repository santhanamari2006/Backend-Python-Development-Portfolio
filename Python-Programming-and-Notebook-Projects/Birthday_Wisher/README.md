1. Project Overview
This project demonstrates how to send automated emails using Python's smtplib library and manage dates effectively using the datetime module. It includes two mini-projects:
1.Motivational Quote Sender – Automatically sends motivational quotes every Monday via email.
2.Automated Birthday Wisher – Sends birthday wishes automatically to people listed in a dataset.

Additionally, the project covers deploying and running Python code in the cloud for automation without relying on a local machine.


2. Learning Objectives
      By completing this project, you will learn how to:
•	Use Python’s smtplib to send emails programmatically.
•	Set up Gmail's SMTP server for email automation.
•	Work with datetime to schedule tasks.
•	Read data from CSV files for event-driven actions.
•	Deploy and run Python scripts in the cloud.


3. Technologies Used
•	Python 3.x
•	smtplib — Send emails via SMTP
•	datetime — Manage and schedule date/time-based actions
•	pandas — Read and process CSV files (optional)
•	Google SMTP (smtp.gmail.com) — Outgoing mail server


4. Cloud Deployment
To run your scripts in the cloud:
•	Use PythonAnywhere, Replit, or AWS Lambda to automate execution.
•	Schedule scripts with cron jobs or cloud schedulers.
