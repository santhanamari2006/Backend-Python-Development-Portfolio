1. Project Overview
The Coffee & WiFi project is a Flask-based web application where users can discover and share cafes with good coffee and WiFi connectivity.
It allows:
•	Adding new cafe entries via a form.
•	Displaying all cafe listings from a CSV file.
•	Using WTForms for form handling.
•	Styling with Bootstrap for a modern UI.


2. Learning Objectives
By building this project, you will:
•	Use Flask to create a dynamic web application.
•	Work with WTForms for structured form input and validation.
•	Use Bootstrap for responsive UI design.
•	Read and write data from/to CSV files.
•	Organize Flask routes, templates, and static files.


3. Features
•	Homepage – Landing page introducing the app.
•	Add Cafe Page – Users can submit cafe details:
o	Cafe Name
o	Location (Google Maps link)
o	Opening & Closing Times
o	Coffee Rating ☕
o	WiFi Strength 📶
o	Power Outlet Availability 🔌
•	Cafe List Page – Displays all cafes in a table from the CSV file.
•	Bootstrap Styling – Clean, mobile-friendly UI.


4. Technologies Used
•	Python 3.x
•	Flask — Backend framework
•	WTForms — Form handling & validation
•	Bootstrap — UI styling
•	CSV — Data storage
•	Jinja2 — HTML templating
